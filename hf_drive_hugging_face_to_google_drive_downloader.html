Quick Setup Guide

        
      

      

        

          
1. Hugging Face Access Token

          
Go to huggingface.co/settings/tokens, create a Read token (starts with hf_), and paste it into the Hugging Face Login card. Public repos also work via Public Guest.

        

        

          
2. Google Drive OAuth Client ID

          
    
            
  1. Open Google Cloud Console → Credentials and enable the Google Drive API.
    2. 
            
  2. Create an OAuth 2.0 Client ID (Application type: Web application).
    3. 
            
  3. Add your current browser origin to Authorized JavaScript origins, then paste the Client ID into the Google Drive card.
    4. 
          

        

        

          
3. Demo Mode & Large Models

          
Toggle Demo Mode in the header to test the full login, browsing, and upload queue flow without credentials. For multi-GB weights, switch to the Python / Colab Script tab to generate a ready-to-run script.
