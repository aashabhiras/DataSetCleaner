# Third-party notices

## Isolate

The Kaggle notebook optionally installs [Isolate](https://github.com/ioi/isolate), a Linux sandbox for running untrusted programs. Isolate is licensed under GNU GPL version 2 or, at the user's option, any later version. It is installed into the ephemeral Kaggle runtime from the project's Debian/Ubuntu package repository; this repository does not bundle Isolate binaries.

The notebook also installs distribution packages for build tools, Node.js, and Java. Their package notices and licenses are supplied by the Kaggle base image's package repositories.
